The first post-apply script stopped because it compared the entire `terraform state list` output against only the six managed resources. Terraform also listed three data resources:

```text

data.aws_iam_policy_document.lambda_assume_role
```

This was a validation-script assertion issue, not an infrastructure or apply failure. The corrected resume path separates managed resources from data resources.

- Terraform produced the exact expected six-resource create plan
