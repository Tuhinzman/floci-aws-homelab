# v0.1 Baseline Validation

**Validation date:** August 30, 2026  
**Status:** PASS

This record captures the first reproducible baseline for the Floci AWS Homelab. It is intentionally limited to workflows that were executed and verified. Private IP addresses, machine identifiers, MAC addresses, SSH material, and test secret values are not included.

| Component | Validated version |

| Kernel | 6.8.0-138-generic |
| Virtualization | Proxmox/KVM |

| Docker Compose | 5.5.0 |
| AWS CLI | 2.36.34 |
| Floci | 1.7.0 |

The starting VM allocation was 6 vCPU, 16 GiB RAM, and an 80 GiB virtual disk.

## Claim boundary

This baseline proves only the workflows listed above. It does not claim end-to-end validation for Lambda, API Gateway, RDS, ECR, EKS, EC2, Kafka, OpenSearch, or other service APIs that may appear in the Floci health response.

The next planned service validation is Lambda using a real Docker-backed execution container.
